# Sistema de Orçamento Imobiliário

Projeto desenvolvido em Python para simular o orçamento de locação de imóveis.

## Funcionalidades

- Apartamentos
- Casas
- Estúdios
- Vagas de garagem
- Desconto para famílias sem filhos
- Parcelamento em até 5 vezes
- Geração de arquivo CSV

## Tecnologias Utilizadas

- Python
- CSV
- Estruturas condicionais
- Funções
- Tratamento de exceções

## Fluxograma

O projeto foi planejado através de um fluxograma antes da implementação.
